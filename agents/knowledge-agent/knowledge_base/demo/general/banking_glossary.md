# Glossaire bancaire

Documentation synthétique destinée à l'environnement de démonstration Smartly Banking AI.

## Objet et périmètre
Solde comptable : écritures comptabilisées. Solde disponible : fonds utilisables après réservations. IBAN : identifiant international de compte. BIC : identifiant de banque. Autorisation : réservation avant comptabilisation. Jour ouvré : jour de traitement bancaire dans le scénario.
